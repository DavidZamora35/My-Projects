# Microbit Snake Game
This is a **Python** project made for the **Microbit** in which you can play a functional snake game.

You can paste the code here: https://python.microbit.org/v/3 to simulate it on a virtual Microbit, or even upload the code to your own.

### Controls:
* A - Turn left
* B - Turn right

### Rules:
* Eat the randomly generated fruit to grow in size!
* Reach the full size of the board without colliding with the wall or yourself to win.
